RequestAssertions

class RequestAssertions

Assertions over a captured RequestSnapshot.

Instances are created by RetrofitTestDsl.verifyRequest and by the annotation driven rule, so assertions never need to be constructed directly.

Every failure message includes the full request, which makes a failing test self explanatory without enabling logging:

rule.verifyRequest {
    hasMethod(HttpMethod.POST)
    hasPath("/users")
    hasHeader("Authorization", "Bearer token")
    hasBody("""{"name":"tom"}""")
}
