RequestSnapshot

data class RequestSnapshot(val sequence: Int, val method: String, val url: String, val path: String, val query: Map<String, List<String>>, val headers: Map<String, List<String>>, val body: String)

An immutable snapshot of an HTTP request captured by the mock server.

The snapshot deliberately does not expose OkHttp's RecordedRequest: the mock server buffers are consumed when read, and leaking OkHttp types into the public API would pin consumers to a specific OkHttp version. Use RequestAssertions (or RetrofitTestDsl.verifyRequest) to assert on a snapshot.
