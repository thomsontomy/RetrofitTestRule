ExpectRequest

annotation class ExpectRequest(val path: String = "", val method: HttpMethod = HttpMethod.ANY, val query: Array<QueryParam> = [], val headers: Array<HeaderValue> = [], val bodyText: String = "", val bodyFile: String = "")

Expectations applied to a captured HTTP request.

Every property is optional. An empty path, an HttpMethod.ANY and empty body properties mean "do not validate this aspect". When both bodyText and bodyFile are set the test fails with an explicit error rather than silently preferring one of them.
