RestRequest

@Repeatable(value = RestRequests::class)
@Target(allowedTargets = [AnnotationTarget.FUNCTION])
annotation class RestRequest(val expect: ExpectRequest = ExpectRequest(), val respond: RespondWith = RespondWith())

Declares the HTTP interaction a test performs.

A single test method may declare the annotation more than once. Requests and responses are matched in declaration order: the first annotation describes the first request the service makes, the second describes the second request, and so on.

@Test
@RestRequest(
    expect = ExpectRequest(path = "/users/me", method = HttpMethod.GET),
    respond = RespondWith(bodyText = """{"id":1}""")
)
@RestRequest(
    expect = ExpectRequest(path = "/users/1/repos", method = HttpMethod.GET),
    respond = RespondWith(bodyText = "[]")
)
fun `loads profile then repositories`() = runTest {
    val service = rule.getService()
    service.me()
    service.repos(1)
}

Every declared request is validated after the test body completes. A test that makes fewer or more calls than it declares fails with a diagnostic instead of silently passing.
