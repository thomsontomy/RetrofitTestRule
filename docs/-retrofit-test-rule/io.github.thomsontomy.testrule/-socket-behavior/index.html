SocketBehavior

enum SocketBehavior : Enum<SocketBehavior>

Low level socket behaviours used to simulate network failures.

Only NORMAL produces a regular HTTP response. The remaining values map to OkHttp's SocketPolicy and are intended for retry, timeout and resilience tests.
